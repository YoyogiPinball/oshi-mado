チャンネルID（UC…） / チャンネルURL / @ハンドル のいずれでもOK。 複数まとめて足すときは1行に1つ貼り付けてください。 推しリストに登録できるのは240チャンネルまでです。 YouTube の登録チャンネルをまとめて取り込む手順は ガイドにあります。

詳細設定

YouTube Data API キー（任意）

配信の開始時刻や配信中／予定／アーカイブの判定、推しリストのアイコンと名前の取得に使います。 未設定でも新着一覧は出ますが、配信は「枠を立てた時刻」に並び、種類の判定はされません。

取得手順（初回のみ・数分で終わります）:

  1. Google Cloud Console を開き、上部でプロジェクトを1つ作成します（既存のものでも構いません）。
  2. YouTube Data API v3 のページで「有効にする」を押します。
  3. 「APIとサービス」→「認証情報」→「認証情報を作成」→「APIキー」を選び、表示された AIza… をコピーします。
  4. 作成したキーを開き、「アプリケーションの制限」は「なし」にします。拡張機能にはリファラー制限が効かないため、制限をかけると通信が弾かれます。
  5. （推奨）「APIの制限」で YouTube Data API v3 のみに絞ると、万一漏れても他のAPIには使えません。
  6. 下の欄に貼り付けて「保存して接続テスト」を押します。

キーの扱いについて
・このキーは chrome.storage.sync に保存され、あなたがログイン中の Chrome 全体に同期されます（他人とは共有されません）。
・送信先は Google の API のみです。推し窓が外部のサーバーへ送ることはありません。
・他人に渡したり、公開リポジトリ・スクショに貼ったりしないでください。
・無料枠は1日あたり1万ユニット。推し窓の消費はごく軽微で、通常は使い切りません（超えても翌日に戻ります）。
・漏れたかも、と思ったら Cloud Console でそのキーを削除し、作り直して入れ直してください。

ヘルプ

詳しい手順は 推し窓ガイド にまとめています。

使い方
  1. 上の「推しを追加」に、チャンネルID・チャンネルURL・@ハンドルを1行に1つ貼り付けて「リストに追加」を押し、最後に「保存」を押します。
  2. （任意）「YouTube Data API キー」を設定すると、配信中・予定・アーカイブの判定と、配信の開始時刻が使えるようになります。
  3. ツールバーの推し窓アイコンを押すと、直近7日の新着が日付ごとに並びます。
  • タブ：配信中 / 全て / 動画 / アーカイブ / 予定 を切り替えます。開いたときは「配信中」です。
  • 全ch：特定の推しの投稿だけに絞り込みます。
  • ⟳：新着を取り直します。⚙：この設定画面を開きます。
  • ⧉ タブで開く：ポップアップではなくブラウザのタブで、広い画面に並べて表示します。
YouTube の登録チャンネルをまとめて取り込む
  1. Google Takeout で「YouTube と YouTube Music」の登録チャンネルだけを選んでエクスポートします。
  2. 届いた ZIP を展開し、登録チャンネルの CSV ファイルをメモ帳などで開きます。
  3. 推しでないチャンネルの行を消してから全体をコピーし、上の「推しを追加」に貼り付けて「リストに追加」→「保存」を押します。登録できるのは240チャンネルまでなので、CSV の行を全部貼らずに絞ってください。

各画面での操作は ガイドの「登録チャンネルをまとめて取り込む」 を見てください。

よくある質問

Q. 推しの投稿が一覧に出てきません
一覧の上部に「新着を取得できませんでした」と出ていれば、そのチャンネルの取得に一時的に失敗しています。YouTube 側がときどきエラーを返すためで、推し窓も自動で2回まで取り直していますが、それでも取れなかったチャンネルです。少し待ってから ⟳ で取り直してください。 出ていない場合は、直近7日に投稿が無いか、推しリストに登録されていない可能性があります。 なお YouTube の公開フィードは1チャンネルにつき最新15件までしか返さないため、投稿の多いチャンネルでは古い投稿が取得できないことがあります。

Q. 推しは何チャンネルまで登録できますか
240チャンネルまでです。推しリストは Chrome の同期用の保存場所に入れていて、1項目の大きさに上限があるためです。 240を超えた状態で「保存」を押すと、保存せずに「あと何件外してください」と表示します。

Q. 「直近7日」はいつから数えていますか
視聴できるようになった時刻で数えます。配信中・アーカイブは配信が始まった時刻、動画・Shorts は公開された時刻です。 ずっと前に告知された配信でも、始まった時点で一覧に出ます。

Q. 予定時刻を過ぎた配信枠が「予定」から消えました
開始予定時刻を24時間過ぎても始まらない枠は、「予定」に出さないようにしています。 配信トラブルで枠を取り直したときの消し忘れや、置きっぱなしのフリーチャット枠がいつまでも残るのを防ぐためです。 予定より遅れて始まった配信は、始まった時点で「配信中」に出ます。 開始予定時刻が設定されていない枠は、枠を立てた時刻から数えます。先の予定は何日先でもそのまま出ます。

Q. Shorts なのに「動画」扱いになっています
YouTube には Shorts かどうかを示す公式の情報が無いため、URL か「60秒以下」で判定しています。60秒を超える Shorts は通常の動画として並ぶことがあります。

Q. コミュニティ投稿は出せますか
出せません。YouTube Data API にコミュニティ投稿を取得する仕組みが無いためです。

動画を YouTube アプリで開くには

カードは通常、ブラウザの新しいタブで開きます。デスクトップの YouTube アプリで開きたい場合は、 Chrome 側を設定します（推し窓側の操作は不要です）。

  1. Chrome で YouTube を開き、アドレスバー右の「インストール」アイコン、または「⋮」→「キャストして保存して共有」→「ページをアプリとしてインストール」で YouTube をアプリ化します。
  2. chrome://apps を開き、YouTube アプリを右クリック →「対応リンクをこのアプリで開く」を有効にします。

※ 環境によっては、拡張機能のポップアップから開くリンクがリンクキャプチャの対象外となり、 上記を設定してもブラウザのタブで開くことがあります。その場合はブラウザ表示のままご利用ください。
