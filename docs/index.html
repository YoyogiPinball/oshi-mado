推し窓ガイド

登録した YouTube チャンネルの新着と配信を1画面にまとめる Chrome 拡張機能「推し窓」の使い方です。

  1. インストールする
  2. 推しを1件ずつ追加する
  3. 登録チャンネルをまとめて取り込む
  4. YouTube Data API キーを設定する（任意）
  5. お問い合わせ

1. インストールする

  1. Chrome ウェブストアの推し窓のページを開き、Chrome に追加 を押します。
  2. ツールバーのパズルのアイコンから推し窓をピン留めしておくと、すぐ開けます。
  3. 推し窓のアイコンを押し、右上の ⚙ で設定画面を開きます。

2. 推しを1件ずつ追加する

設定画面の一番上にある「推しを追加」の欄に、次のどれかを1行に1つ貼り付けます。

  • チャンネルID（UC で始まる24文字）
  • チャンネルページの URL（例: https://www.youtube.com/@example）
  • @ハンドル（例: @example）

リストに追加 を押すと、下の「推しリスト」に「新規」の印つきで並びます。最後に 保存 を押すと確定します。保存を押す前に画面を閉じようとすると、確認が出ます。

3. 登録チャンネルをまとめて取り込む

YouTube で登録しているチャンネルを一覧ファイル（CSV）に書き出し、その中身を推し窓に貼り付けます。 書き出しには Google 公式のデータ持ち出しサービス Google Takeout を使います。 推し窓に Google アカウントへのログインを許可する必要はありません。

ボタンやファイルの名前は、Google アカウントの表示言語によって変わります。以下は日本語表示の場合です。英語表示では、フォルダーやファイルが subscriptions.csv のような英語名になります。

3-1. Google Takeout で書き出す

  1. takeout.google.com を開きます。YouTube で使っている Google アカウントでログインしてください。
  2. 「エクスポートに含めるデータの選択」の一覧の上にある 選択をすべて解除 を押します。最初は全サービスにチェックが入っているためです。
  3. 一覧を下へスクロールし、YouTube と YouTube Music にだけチェックを入れます。
  4. その項目の中にある すべての YouTube データが含まれます を押します。開いた画面でいったんすべてのチェックを外し、登録チャンネル にだけチェックを入れて OK を押します。視聴履歴などを含めないので、書き出しが早く終わります。
  5. 一覧の一番下の 次のステップ を押します。
  6. 「ファイル形式、エクスポート回数、エクスポート先の選択」の画面になります。最初から次の値が選ばれているので、何も変えずに一番下の エクスポートを作成 を押します。
    • エクスポート先: ダウンロード リンクをメールで送信
    • 頻度: 1 回のエクスポート
    • ファイル形式: .zip
    • ファイルサイズ: 2 GB（登録チャンネルの一覧だけなら 2 GB に届かないので、ファイルが分かれることはまずありません）
    ここの値は変えても構いません。どの組み合わせでも、最終的に登録チャンネルの CSV ファイルが手に入れば推し窓に取り込めます。迷ったら最初の値のままで大丈夫です。
  7. 準備ができると、Google からメールが届きます。登録チャンネルだけなら数分で終わることが多いですが、数時間かかることもあります。
  8. メールの ファイルをダウンロード を押し、ZIP ファイルを保存します。途中でパスワードの入力を求められることがあります。ダウンロードできるのはメールが届いてから1週間です。

3-2. CSV ファイルを開く

  1. ダウンロードした ZIP ファイルを展開します（Windows では右クリック → すべて展開）。
  2. 中にある登録チャンネルの CSV ファイルを探します。日本語表示ではおおよそ次の場所です。 Takeout / YouTube と YouTube Music / 登録チャンネル / 登録チャンネル.csv
  3. ファイルを右クリック → プログラムから開く → メモ帳 で開きます。1行に1チャンネルずつ、チャンネルID・URL・チャンネル名が並んでいます。

ダブルクリックすると Excel などの表計算ソフトで開くことがあります。そのまま保存すると形式が変わることがあるので、メモ帳などのテキストエディターで開くのがおすすめです。

3-3. 推し窓に貼り付ける

  1. 推しとして見たいチャンネル以外の行を消します。CSV には登録しているチャンネルが全部入っています。
  2. 残った行をすべて選択してコピーします（Ctrl + A → Ctrl + C）。
  3. 推し窓の設定画面を開き、「推しを追加」の欄に貼り付けて リストに追加 を押します。
  4. 「推しリスト」に並んだ名前を確かめ、不要なものがあれば 外す を押します。
  5. 最後に 保存 を押します。

1行目の見出しの行（列の名前が並んだ行）は、貼り付けても「解決できず」と表示されるだけで、登録には影響しません。消してから貼り付けても構いません。

推しリストに登録できるのは 240 チャンネルまでです。Chrome の同期ストレージの容量に上限があるためです。登録チャンネルが多い場合は、行を絞ってから貼り付けてください。

4. YouTube Data API キーを設定する（任意）

キーが無くても新着一覧は出ます。キーを設定すると、配信中・予定・アーカイブの判定、配信の開始時刻、推しリストのアイコンと名前が使えるようになります。 キーは自分の Google Cloud プロジェクトで作ったものを使います（開発者が用意したキーを共有する方式ではありません）。

  1. Google Cloud Console を開き、プロジェクトを1つ作成します（既存のものでも構いません）。
  2. YouTube Data API v3 のページで 有効にする を押します。
  3. 「APIとサービス」→「認証情報」→「認証情報を作成」→ APIキー を選び、表示された AIza… で始まるキーをコピーします。
  4. 作成したキーを開き、「アプリケーションの制限」は なし にします。拡張機能にはリファラー制限が効かないため、制限をかけると通信が弾かれます。
  5. （推奨）「APIの制限」で YouTube Data API v3 だけに絞ります。万一キーが漏れても、ほかの API には使えなくなります。
  6. 推し窓の設定画面の「詳細設定」→「YouTube Data API キー（任意）」に貼り付けて 保存して接続テスト を押します。

キーは他人に渡したり、スクリーンショットや公開リポジトリに載せたりしないでください。無料枠は1日1万ユニットで、推し窓の消費は1回の更新でおおむね1ユニットです。
